# API_CONTRACTS — проектные контракты (не исполненная OpenAPI спецификация)

Base: `https://veriq.void-rp.ru/api/v1`. OpenAPI generated by FastAPI from typed contracts; `/docs` disabled/public-protected in prod. No implicit trust in tenant header.

## Системные пробы Foundation

- `GET /health/live` возвращает `200 {"status":"ok"}`, пока процесс обслуживает запросы.
- `GET /health/ready` проверяет PostgreSQL и Redis и возвращает `200 {"status":"ok"}` или `503 DEPENDENCY_UNAVAILABLE` в общем формате ошибок. Ответ не кэшируется. Обе пробы обходятся без данных организаций и пользователей.

## Формат ошибок
`{ "error": {"code":"ATTEMPT_CLOSED", "message":"...", "request_id":"uuid", "details":{} } }`; status codes 400/401/403/404/409/422/429; не раскрывать существование чужих tenant объектов. `Idempotency-Key` для creation/submit/commands; optimistic concurrency via `If-Match` или `expected_revision`.

## Attempt lifecycle
- `POST /assignments/{id}/attempts` → idempotently reserve attempt, `preflight_required` may be returned.
- `POST /attempts/{id}/preflight` → agent required/pairing state, start eligibility.
- `POST /attempts/{id}/start` → `attempt_id`, server_now, deadline, version, variant view **without hidden answer keys**.
- `GET /attempts/{id}` → snapshot, confirmed revisions, lease status.
- `PUT /attempts/{id}/answers/{item_id}` with `client_operation_id`, `expected_revision`, payload; reply revision/server_confirmed_at.
- `POST /attempts/{id}/submit` (Idempotency-Key) → queued/under_review/submitted.
- `POST /attempts/{id}/pause|resume|extend|force-submit` → teacher permissions + audit + atomic version check.
- `POST /attempts/{id}/takeover` → new authoritative control lease; for agent-required new pairing when moving devices.
- `GET /attempts/{id}/result` → visibility gated.

Example save request:
```json
{"client_operation_id":"uuid", "expected_revision":2, "answer":{"type":"short_text","value":"42"}}
```
Example success:
```json
{"answer_revision":3,"server_confirmed_at":"2026-11-12T09:00:00Z","attempt_version":9}
```
Error `409 REVISION_CONFLICT` provides sanitized latest answer revision (if authorized); `409 ATTEMPT_CLOSED` if after deadline; `423 TECHNICAL_PAUSE` for strict connectivity policy.

## Agent & Admin
`POST /agent-enrollments` admin with step-up; `POST /agents/enrollment/request` device proof; `POST /agent-enrollment-requests/{id}/approve|reject`.
`GET /agents/me/config`, `POST /agents/events/batch`, `POST /agents/heartbeat` (or secure control channel); `GET /organizations/{org}/devices`; `POST /devices/{id}/commands` allowlisted, TTL.
`POST /attempts/{id}/pairing-code` browser auth; `POST /agents/pairings/redeem` device auth; `POST /attempts/{id}/pairing-confirm` session proof; `POST /proctoring/{id}/viewer-token` actor auth with exact scope; `POST /proctoring/{id}/stop`.
`WSS /api/v1/agents/control` authorized by device key challenge, not student bearer; `WSS /api/v1/attempts/{id}/events` browser authenticated for reconnect and teacher commands.

## Events
Envelope: `event_id`, `kind`, `schema_version`, `server_seq`, `server_at`, `entity_id`, `payload`; resume by last seq; duplicate events ignored.
Kinds: `attempt.timer_updated`, `attempt.paused`, `attempt.resumed`, `answer.confirmed`, `agent.connected`, `agent.disconnected`, `incident.created`, `viewer.joined`, `viewer.left`, `grade.published`.

## Security constraints
Tenant-scoped generated OpenAPI schema; no agent secret in JS; signed opaque one-use pairing grant; local Bridge origin validation and strong anti-CSRF; never put browser auth tokens in `veriq://` URL; short TTL and explicit user gesture; login required for browser side.
No generic remote shell; no arbitrary file fetch by URL; media tokens publish/subscribe permissions limited room, track, short TTL and active disconnect on revoke. Audit viewer join/leave.

## Storage
`GET /admin/storage/summary`, `/admin/backups`, `/admin/storage/cleanup-candidates`, `POST /admin/storage/cleanup-dry-run`, `POST /admin/storage/cleanup-jobs` with step-up and approval, `GET /admin/storage/cleanup-jobs/{id}`; never arbitrary filesystem paths accepted from client.
