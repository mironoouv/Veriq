# Передача контекста

Veriq — мультиарендная платформа для экзаменов с серверным состоянием, опциональным Windows Agent и отдельным Judge. Требования в [VERIQ_SPEC](../VERIQ_SPEC.md), утверждённые решения в [реестре и ADR](DECISIONS.md), порядок работ в [ROADMAP](../../planning/ROADMAP.md).

Foundation 1b добавил PostgreSQL-очередь системных задач, внутренний Redis для сигналов и отдельный worker с короткой SQL-пробой. См. [состояние и проверенный коммит](PROJECT_STATE.md). При продолжении проверь HEAD, рабочее дерево и проверки PR #2, затем загрузи нужную область из [индекса](CONTEXT_INDEX.md).

Согласование владельца требуется для перехода к 1c, изменения утверждённых ADR и объединения PR #2. Сохранность Docker-данных проверяй без удаления томов. Условия для долгих задач описаны как предложение в [документации worker](../../services/worker/README.md).
