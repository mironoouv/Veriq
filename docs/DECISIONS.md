# Реестр решений — утверждено владельцем проекта

`APPROVED` означает обсуждено и подтверждено; реализация ещё не выполнена. Кодовое имя решения отражает группу требований.

| ADR | Статус | Содержание |
|---|---|---|
| 001 | APPROVED | Обязательность Agent — параметр конкретной работы; браузерный режим допустим |
| 002 | APPROVED | Агент централизованно управляется из админки, группы ПК, команды и аудит |
| 003 | APPROVED | Комбинированное вступление: саморегистрация, приглашения, коды групп, заявки, CSV/XLSX импорт |
| 004 | APPROVED | Гибкие оценки: баллы, проценты, 5-балльная шкала, зачёт, шкалы организации |
| 005 | APPROVED | Личные и общие банки вопросов, доступ коллегам и организации |
| 006 | APPROVED | Назначение через календарь и через список назначенных работ |
| 007 | APPROVED | Свободная навигация, пауза преподавателем, восстановление, публикация, журнал, одна управляющая сессия |
| 008 | APPROVED | Строгий/ограниченный офлайн режим настраивается отдельно для работы |
| 009 | APPROVED | Профили прокторинга + ручные допустимые настройки |
| 010 | APPROVED | Настраиваемые реакции на события; неоднозначные события не являются автоматическим доказательством |
| 011 | APPROVED | Ручное и массовое развёртывание Agent с централизованным одобрением устройств |
| 012 | APPROVED | Только live-трансляции, **никаких видеозаписей, серверных скриншотов, архивов** |
| 013 | APPROVED | Настраиваемый срок хранения инцидентов на организацию, автоудаление |
| 014 | APPROVED | MFA обязательно: Superadmin, Org Admin, Technician; другие роли — политика организации |
| 015 | APPROVED | Восстановление MFA: резервные коды + усиленная независимая проверка + аудит |
| 016 | APPROVED | Повышенная надёжность: WAL, отдельные backup, проверки; target RPO ≤5 мин, RTO ≤1 ч; админка хранения и безопасной очистки |

Также APPROVED: название Veriq, домен `veriq.void-rp.ru`, multi-tenant с Superadmin, единая учётная запись на несколько организаций, monorepo, Windows/Docker dev → Linux/Docker production, FastAPI/PostgreSQL/Vue3/Vite/Tailwind4/daisyUI5/i18n, C# Agent, isolated Code/SQL Judge; полный набор из восьми настроек работ (таймер, попытки, random, автосохранение, Agent required, отложенные ответы, ручная проверка, расписание/дедлайн).

## Не перепутать с утверждёнными решениями
`LiveKit`, `pgBackRest`, `WPF`, `WiX MSI`, `Redis`, `SQLAlchemy/Alembic`, `TOTP + passkeys` — технические рекомендации реализации. Некоторые практически выбраны в проектном плане, но требуют совместимости/PoC и не должны подаваться как завершённые интеграции. Вопросы в `OPEN_QUESTIONS.md`.
